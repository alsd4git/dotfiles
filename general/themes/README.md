# Oh My Posh theme

`tokyo.omp.json` is the unmodified Tokyo theme from Oh My Posh v29.13.1,
matching the prompt version used when it was added. It is distributed under
the upstream MIT license in `LICENSE.oh-my-posh`.

Source: https://github.com/JanDeDobbeleer/oh-my-posh/blob/v29.13.1/themes/tokyo.omp.json

The installer manages a symlink or copy under
`${XDG_CONFIG_HOME:-$HOME/.config}/oh-my-posh/themes/`. Both Bash and Zsh use
this persistent path, including on macOS. Updating the binary or removing
its download cache does not replace the versioned theme. Update this file
explicitly when adopting changes to Tokyo, keeping the source version and
license documented here.
